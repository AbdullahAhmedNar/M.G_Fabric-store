# 📦 دليل تثبيت وتشغيل نظام M.G Fabric Store

## 🎯 المتطلبات الأساسية

قبل البدء، تأكد من تثبيت:

### 1. Node.js (إصدار 18 أو أحدث)
- قم بتحميله من: https://nodejs.org/
- اختر نسخة LTS (الموصى بها)
- **مهم:** أثناء التثبيت، تأكد من تفعيل خيار "Add to PATH"

### 2. التحقق من التثبيت
افتح Command Prompt أو PowerShell واكتب:
```bash
node --version
npm --version
```
يجب أن تظهر أرقام الإصدارات (مثل: v18.17.0 و 9.6.7)

---

## 🚀 خطوات التثبيت

### الخطوة 1: فك الضغط
1. قم بفك ضغط ملف `M.G_SYSTEM.zip` إلى مجلد على جهازك
2. **مهم:** اختر مسار بدون مسافات أو أحرف عربية (مثل: `C:\Projects\MG_System`)

### الخطوة 2: تثبيت المكتبات
1. افتح Command Prompt **كمسؤول** (Run as Administrator)
2. انتقل إلى مجلد البرنامج:
```bash
cd "C:\Projects\MG_System\m.g_program"
```

3. قم بتثبيت المكتبات:
```bash
npm install
```

⏳ **ملاحظة:** قد تستغرق هذه العملية 5-10 دقائق في المرة الأولى

### الخطوة 3: التحقق من التثبيت
تأكد من عدم ظهور أخطاء في النافذة. إذا ظهرت أخطاء:
- تأكد من اتصال الإنترنت
- قم بحذف مجلد `node_modules` والملف `package-lock.json` ثم أعد المحاولة

## ▶️ تشغيل البرنامج

### للتشغيل اليومي (الطريقة الأسهل)

**الطريقة 1: باستخدام الأمر المباشر**
```bash
npm start
```

**الطريقة 2: إنشاء ملف تشغيل سريع**
قم بإنشاء ملف نصي جديد `START.bat` في مجلد `m.g_program`:
```batch
@echo off
cd /d "%~dp0"
echo 🚀 بدء تشغيل نظام M.G Fabric Store...
echo.
npm start
pause
```

احفظ الملف ثم اضغط عليه مرتين للتشغيل.

### ما يحدث عند التشغيل:
1. ✅ يبدأ السيرفر على المنفذ 3456
2. ✅ يفتح البرنامج تلقائياً في نافذة
3. ✅ قاعدة البيانات تُنشأ تلقائياً في `data/fabric_store.db`

## 🛠️ حل المشاكل الشائعة

### ❌ المشكلة: "Cannot find module"
**الحل:**
```bash
# احذف المجلدات والملفات القديمة
rmdir /s /q node_modules
del package-lock.json

# أعد التثبيت
npm install
```

### ❌ المشكلة: خطأ 500 من الـ API
**الحل:**
1. تأكد من وجود مجلد `data` في نفس مستوى مجلد `server`
2. تحقق من صلاحيات الكتابة على المجلد
3. احذف ملف قاعدة البيانات واتركه يُنشأ من جديد:
```bash
del data\fabric_store.db
npm start
```

### ❌ المشكلة: "Port 3456 is already in use"
**الحل:**
هناك نسخة أخرى من البرنامج تعمل. قم بإغلاقها أو:

**على Windows:**
```bash
# ابحث عن العملية
netstat -ano | findstr :3456

# أغلق العملية (استبدل PID برقم العملية)
taskkill /PID [رقم_العملية] /F
```

### ❌ المشكلة: البرنامج لا يفتح تلقائياً
**الحل:**
افتح المتصفح يدوياً وانتقل إلى:
```
http://localhost:5173
```

### ❌ المشكلة: بيانات الإحصائيات لا تظهر
**الحل:**
1. تحقق من وجود بيانات في قاعدة البيانات
2. افتح أدوات المطور في المتصفح (F12) وتحقق من الأخطاء
3. أعد تشغيل البرنامج

## 📝 ملاحظات هامة

### ✅ نظام حساب الربح والخسارة:
- **المبيعات:** تُحسب كإيرادات
- **تكلفة البضاعة المباعة:** تُطرح (للأصناف المباعة فقط، وليس كل المشتريات)
- **المصروفات الخارجية:** تُطرح (إيجار، كهرباء، رواتب، إلخ)
- **المصروفات الداخلية:** تُضاف (إيرادات إضافية، عمولات، إلخ)

**المعادلة:**
```
صافي الربح = المبيعات - تكلفة البضاعة المباعة - مصروفات خارجية + مصروفات داخلية
```

### ✅ التكلفة والربح:
- عند البيع من المخزون، يُحسب الربح تلقائياً بناءً على سعر التكلفة المسجل
- إذا كان سعر التكلفة = 0، سيظهر تحذير في صفحة المبيعات
- البضاعة المتبقية في المخزون **لا تؤثر** على الربح حتى يتم بيعها

### ✅ الوحدات:
- الأصناف يمكن أن تكون بوحدة "متر" أو "كيلو"
- عند البيع من المخزون، الوحدة تُستخدم تلقائياً من بيانات الصنف

## 📞 الدعم الفني

في حالة مواجهة أي مشكلة:
1. راجع قسم "حل المشاكل الشائعة" أعلاه
2. تحقق من ملف `server/error.log` إن وُجد
3. افتح أدوات المطور في المتصفح (F12) وتحقق من رسائل الأخطاء
4. تواصل مع فريق الدعم مع إرفاق:
   - لقطة شاشة للخطأ
   - محتوى ملف `error.log`
   - خطوات إعادة إنتاج المشكلة
